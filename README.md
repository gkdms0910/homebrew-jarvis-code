# Jarvis Code Homebrew Tap

```bash
brew install --cask gkdms0910/jarvis-code/jarvis-code
```

또는:

```bash
brew tap gkdms0910/jarvis-code
brew install --cask jarvis-code
```

macOS 12+, Node.js(Homebrew 자동 설치), 별도의 Codex CLI 및 로그인이 필요합니다.

```bash
brew update
brew upgrade --cask jarvis-code
brew uninstall --cask jarvis-code
```

[소스와 설치 문서](https://github.com/gkdms0910/jarvis-code/blob/main/docs/installation.md).
설치된 v1.0.0 앱에서 복원한 개인 배포본이며 Apple 서명·공증은 포함되지 않습니다.
